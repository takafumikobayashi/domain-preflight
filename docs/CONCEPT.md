# コンセプト — Domain Preflight

## 1. 一文で表すと

**Webサイトやドメインの設定を、AIと一緒に理解し、安全に改善するためのオープンソースの点検ツールキット。**

英語のメッセージ: **Know your site. Secure your setup.**

「Preflight」は航空機の飛行前点検を意味する。公開前の確認に加え、運用中の変更前・定期点検にも使う名称として採用する。

## 2. 解決したい課題

Webサイト運営者は、DNS、HTTPS、証明書、メール認証、WAF、アクセス制御などの設定を複数サービスに分けて持つことが多い。管理画面が分散し、関連する仕様も複雑である。

その結果、次のような課題が発生する。

- DNS移行時にWebサイト以外のレコード（メール、認証等）を見落としやすい。
- `HSTS`、`DMARC`、`DNSSEC`などの設定の意味と適用条件が分かりにくい。
- 以前の用途で作ったAccessアプリやDNSレコードが残る。
- 「設定されている」ことと「正しく機能している」ことが混同される。
- 既存の診断サービスが見つけた問題を、**自分の利用環境に適した改善手順**へ落とし込めない。

## 3. 開発のきっかけ

実際のサイト運営で、Cloudflare `cf` CLI、Netlify CLI、AWS CLIを使い、DNSの棚卸し、不要な設定の整理、ゾーン間の設定比較、別DNSプロバイダーからの移行、TLS・HSTS・メール認証の確認を行った。

その経験から、**調査 → 根拠の整理 → 改善候補の提示 → 人間の承認 → 変更後の検証**を、再利用可能な手順として提供できると考えた。

ただし、本プロジェクトのMVPは**調査と改善提案まで**とする。実際の変更・ロールバックは後続フェーズで別途検討する。

## 4. 誰に価値を提供するか

| 利用者 | 得たい価値 |
| --- | --- |
| 個人ブログ・個人開発者 | ドメイン設定の見落としを手軽に把握できる |
| 小規模事業者・地域団体 | 専門知識が十分なくても、状況と相談事項を理解できる |
| Web制作・保守担当者 | 納品・変更前後の点検結果を記録しやすい |
| AIコーディングエージェント利用者 | CLIとスキル経由で、調査と報告を効率化できる |

## 5. 提供価値の中心

1. **観測できた事実の明示**: 何を・いつ・どこから確認したかを残す。
2. **正確な不確実性の扱い**: 未検査、確認不能、要判断を明確に区別する。
3. **用途に応じた説明**: 例えばメールを使わないドメインに限りNull MX / SPF `-all` / DMARCの組み合わせを検討する。メール使用の有無を確認せず提案しない。
4. **安全な改善支援**: 設定変更の自動化より、変更前の理解・検証を優先する。
5. **公開情報だけでも利用可能**: Cloudflareアカウントを持たない人にも提供する。

## 6. 既存ツールとの違い（目標）

汎用DNSチェッカーやHTTPヘッダー診断を単に再実装することが目的ではない。公開情報の検査と（任意の）Cloudflare内部設定を結びつけ、**状況依存の説明・根拠・未確認事項・次に取るべき行動**を日本語で分かりやすく示す。

AIエージェントがあってもなくても使えるよう、**判定処理をCLI本体に、自然言語での案内をAgent Skillに**分離する。

## 7. やらないこと

- Webサイトの安全性を100%保証しない。
- 総合スコアだけで「安全」「危険」を断定しない。
- 侵入テスト、脆弱性スキャン、大量リクエスト送信は行わない。
- 認証情報、DNS、WAF、HSTS、DMARCなどを確認なしに変更しない。
- Cloudflareだけに依存する製品にはしない。
- 利用者の設定やシークレットを外部サービスへ勝手に送らない。

## 8. 成功の定義

- 初めて使う人でも、自分のドメインで確認できる項目と確認できない項目が分かる。
- 出力には事実・根拠・改善候補・注意事項が含まれ、他者と共有できる。
- Cloudflare連携の有無にかかわらず、同じレポート構造を使える。
- 全MVP処理で、対象サービスの設定を変更せずに終了する。
