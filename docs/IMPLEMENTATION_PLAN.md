## Phase 5以降（別リリース）

1. **DNS Migration Assistant** — Netlify等とCloudflareのレコード比較、移行前後の検証。自動変更は別途安全設計。
2. **Resource Cleaner** — 不要と思われる設定の**候補**抽出。誤削除防止のため自動削除はしない。
3. **Drift Watch** — ベースライン保存と差分検出。秘密情報の除外を徹底する。
4. **プロバイダー拡張** — Netlify、AWSなどをプラグイン方式で追加。

## テストすべき代表シナリオ

- [x] DNSレコードが取得できない / 1種だけない / CNAMEがある
- [x] HTTPでHTTPSへ転送 / 転送なし / 無限リダイレクト
- [x] 自己署名・期限切れ・ホスト名不一致の証明書
- [x] HSTS未設定 / 1日 / `includeSubDomains`あり

- [x] DMARCなし / `p=none` / `p=reject` / メール用途不明
- [x] DKIMセレクタなし -> `not_checked`
- [ ] Cloudflare未認証 / 権限不足 / DNS-only / proxied
- [x] 不正ホスト、内部IPへのリダイレクト（異常に大きい応答は本文を読まない設計で回避）
- [x] APIトークンを含むエラー文字列がレポートに出ない（Phase 1 は環境変数を読まない。Phase 3 で `cf` の標準エラーのマスキングを追加）
